## 검증

- TypeScript 검사: 통과.
- Next.js 프로덕션 빌드: 로컬 및 Vercel 통과.
- 핵심 테스트: 56/56 통과 (6민원 x 8선택 조합, 6언어 데이터 완전성, 진행 복원·만료·버전 변경, 참조 검증, 암호/세션, CSRF, 저장 충돌, 감사 이력, GitHub 대용량 blob 저장 모의 테스트).
- 배포된 Chrome 브라우저: 6개 언어 제목/안내 전환, 6개 민원 진입, 기타 민원 2단계, 여권 복사·등록증 납부 선택 시 5단계 생성, 체크 1개 완료 후 2단계 상태 새로고침 복원 확인.
- 직원 도움 창 열기/닫기 및 한글 직원 안내 확인.
- 신청서 도우미 7개 항목, 개인정보 입력창 0개 확인.
- 상태 API HTTP 200, runtimeAI:false / pilot:true 확인.
- 관리자 비로그인 API 요청은 401. 연결 도구가 이를 보호 배포로 오분류하여 읽기에 실패했으므로 상태 코드는 관측했지만 브라우저 인증 E2E 성공으로 간주하지 않음.
- 브라우저 콘솔에서 앱 오류는 관측되지 않았으며 브라우저 확장 자체의 메타데이터 오류만 관측.
- iPhone WebKit / Pixel Chromium E2E 32건 작성. **미실행**: 실행 파일 다운로드 결과가 유효한 ZIP이 아니어서 브라우저 설치 실패. 실제 iPhone·Android 실기 검증도 미실시.
- 로컬 미리보기 브라우저는 보안 정책 차단으로 더 이상 시도하지 않았고, 별도로 요청된 Vercel 배포 화면에서 검증. 보호 설정을 해제하거나 보안 정책을 우회하지 않음.

## 디자인 검토

Image Gen의 내부 3화면 콘셉트와 브라우저 스크린샷을 검토했습니다. 비교 지점: 네이비 헤더, 녹색 주요 버튼, 앰버 시범 경고, 큰 번호와 단계 진행률, 3열 언어 선택, 선형 민원 목록, 위치 미확정 회색 영역, 관리자 좌측 탐색/편집 구조.

콘셉트 생성 이미지의 잘못된 일본어/크메르어 및 일반 주민업무 예시는 채택하지 않고 사용자가 지정한 6언어와 6민원으로 구현했습니다. 불필요한 메뉴 아이콘과 휴대폰 기기 목업, 확정되지 않은 준비물 예시는 제외했습니다. 콘텐츠 정확성을 위한 의도적 차이입니다. 데스크톱 현재 뷰포트만 스크린샷 검토했으며 콘셉트 원본과 동일한 모바일 크기에서 픽셀 단위 비교나 독립 view_image 재검증은 완료하지 못했습니다.

## QR와 현장 입력

`qr/`에 입구 및 6시설 QR, 각각 SVG와 PNG 제공. `targets.json`에 실제 연결 주소 기록. Preview 주소 변경 또는 새 배포를 쓰면 QR을 다시 생성해야 합니다. 고정 운영 도메인 확정 전에는 대량 인쇄하지 마세요.

시설과 평면도는 `/admin`에서 6언어 설명 및 사진/경로 이미지를 올리고 검수 완료로 전환하면 표시됩니다. 검수 대기 상태에서는 실제 위치·사진·동선을 주장하지 않습니다. 민원 순서·조건·준비물·수수료·번역·공지 편집도 관리자에서 수행합니다. 시설/민원 신규 추가와 ID 변경은 검증되는 JSON 편집기로 가능합니다.

3. 직원이 현장 단계·시설 위치·서식 최신본·자격별 필요 서류·수수료/면제와 ATM 절차 검수.

5. 기관 승인, 고정 도메인과 QR 인쇄, 운영 담당자/변경 승인·복원 절차 확정.
