# VISABLE GUIDE

제주출입국 민원실 다국어 모바일 안내의 **비공식 시범 서비스**. 공식기관 승인을 받지 않았습니다. 실제 행정 접수·결제·승인 시스템이 아닙니다.

Next.js 16 / React 19 / TypeScript / Tailwind CSS 4. 런타임 LLM·번역 API 호출 0. 방문객 로그인·개인정보 입력 없음. 기존 VISABLE 저장소와 독립.

## 실행

Node.js 24, npm. `npm ci`, `npm run dev` 후 http://localhost:4173. `npm run build`, `npm start`로 프로덕션 실행. 기본 암호 없음. 개인정보가 포함된 문서를 저장소나 앱에 넣지 마세요.

## 구현 범위

- 한국어 / 영어 / 중국어 간체 / 인도네시아어 / 힌디어 / 베트남어
- 6개 민원. 구체적인 민원은 신청서 작성부터 안내하며, 직원 확인 단계를 반복하지 않습니다. 기타 민원은 유형 문의 화면으로 바로 이동. 여권 복사·수입인지·카드 발급비용은 안내받은 경우에만 선택
- 체크리스트와 언어·단계는 해당 기기에 최대 24시간 보관. 콘텐츠 버전 변경 시 오래된 기록 초기화. 삭제 버튼 제공
- 통합신청서 항목별 설명 7개. 종이 서식 도움만 제공하며 앱 안에 개인정보 입력창 없음
- 시설별 고유 URL `/?facility=info|forms|copy|stamps|atm|counter`
- 시설 위치·사진·경로·평면도는 검수 완료 후 표시. 현재 실제 위치나 경로를 주장하지 않음
- 관리자 암호 인증, HttpOnly/SameSite 세션, 서버 권한 검사, CSRF Origin 검사, 입력 스키마 검증
- 변경 사유·수정자·리비전·시각·해시 연결 변경 이력, 동시 수정 충돌 거부
- 시설별 QR 다운로드, 매니페스트·아이콘·서비스워커·6언어 오프라인 복구 페이지

## 관리자 설정

`/admin`은 관리자 암호가 없으면 인증을 거부합니다. 게시 토큰이 없으면 온라인 저장을 차단하고 초안 JSON 다운로드만 허용합니다. 설정 준비 상태는 로그인 화면에서 확인할 수 있습니다. 방문객에게 임시 관리자 암호를 공개하지 마세요.

1. 자신의 신뢰할 수 있는 로컬 터미널에서 `node --import tsx scripts/admin-key.ts` 실행. 20자 이상의 강한 암호 입력. 터미널 입력은 화면에 보일 수 있으니 화면 공유를 끄세요.
2. 출력된 `ADMIN_PASSWORD_HASH`, `ADMIN_SESSION_SECRET`를 **Vercel 프로젝트 Settings → Environment Variables → Preview**에만 입력. 암호·토큰을 채팅·GitHub·명령행 인수에 붙여 넣지 마세요.
3. 선택적으로 `ADMIN_USERNAME`(수정자 표시명)을 설정. 현재 MVP는 단일 운영자 인증입니다. 여러 사람이 공용 암호를 쓰면 개인별 책임을 구별할 수 없으므로 정식 운영 전에 개별 계정/SSO로 교체하세요.
4. 재배포 후 `/admin` 로그인. 세션은 2시간 유효하며 암호 해시나 세션 비밀키 변경 시 기존 세션 무효화.

### Vercel 영구 저장

Vercel 함수의 파일시스템을 영구 저장소로 사용하지 않습니다. GitHub Contents API로 콘텐츠와 변경 이력을 **하나의 JSON 파일에 원자적으로 커밋**합니다. 서버에만 있는 제한된 토큰으로 호출하며 방문객에게 노출하지 않습니다. 신규 유료 서비스는 필요하지 않습니다.

- 신규 `club-paradiso/visable-guide`에 `content` 브랜치를 생성 (main에서 분기). 배포할 코드는 `preview/mvp` 브랜치, 운영 콘텐츠는 `content` 브랜치로 분리.
- GitHub fine-grained token: **visable-guide 저장소 하나만**, Contents Read and write. 기존 VISABLE 권한 불필요. 관리자 앱에서 토큰을 발급하지 않습니다.
- Vercel Preview 환경변수: `CONTENT_GITHUB_TOKEN`, `CONTENT_GITHUB_REPO=club-paradiso/visable-guide`, `CONTENT_GITHUB_BRANCH=content`, `CONTENT_GITHUB_PATH=data/published.json`.
- 공개 저장소의 콘텐츠는 쓰기 토큰 없이도 읽을 수 있습니다. 읽기 실패 시 검수 대기 기본 데이터를 표시합니다. 게시 토큰 설정 후 콘텐츠 파일이 없으면 첫 저장 때 생성합니다. 브랜치가 없거나 권한이 틀리면 저장 실패를 표시. 저장 성공 없이 게시 성공이라고 표시하지 않음.
- API 응답에서 토큰·환경변수 값을 반환하지 않음. 공개 콘텐츠와 변경 이력은 public 저장소에 남으므로 민원인 정보·비밀값·내부 전용 자료를 넣지 마세요. 방문객 `/api/content`에는 변경 이력·수정자 정보 제외.
- 사진과 평면도는 브라우저에서 재인코딩/축소 후 JSON에 포함. 파일당 약 600KB, 전체 문서 약 2.4MB 제한. 대용량 자료실 용도가 아님.
- GitHub SHA를 이용해 갱신 충돌 시 409 반환. 이전 콘텐츠와 이미지 복원은 해당 `content` 브랜치 Git 커밋을 검토해 복원. 수정 이력의 해시 연결은 사고 조사 보조이며 독립된 불변 감사 저장소는 아님.

로컬 개발은 `CONTENT_LOCAL_DIR=runtime`으로 원자적 파일 저장/잠금. `runtime/`은 Git 제외. Vercel에서는 이 방식의 쓰기를 거부합니다.

## 현장 자료 입력

1. 관리자 → 시설·사진·경로: 시설 선택 → 6개 언어 이름/설명/위치 입력 → 승인된 현장 사진 업로드 → 위치 확인 완료 선택. 미검수 위치와 경로는 방문객에게 숨김.
2. 관리자 → 청사 평면도: 개인정보 없는 평면도 업로드 → 언어별 대체 설명 → 현장 확인 완료.
3. 경로 안내는 관리자 검수 경로 이미지 업로드 방식. 자동 길찾기·실내 GPS 없음. 각 시설 경로 이미지를 직접 확인하고 올리세요.
4. 민원 유형에서 단계 순서를 변경하고, 절차 탭에서 조건·준비물·주의사항·수수료 문구를 편집.
5. 유형/시설/단계 추가·삭제와 고유 ID 변경은 전체 JSON 편집에서 수행. 서버가 참조·중복·6개 언어 누락을 검증. 시설 ID를 바꾸면 기존 인쇄 QR도 바뀌므로 고정 유지 권장.
6. 모든 저장은 5자 이상 변경 사유가 필요. rN 충돌이면 다시 불러온 최신 내용과 비교 후 재수정.
7. 관리자 QR 탭에서 실제 URL의 SVG 다운로드. 대량 파일은 `node --import tsx scripts/generate-qr.ts https://실제-배포주소`. 현재 QR은 고정 테스트 주소 `https://visable-guide-git-preview-mvp-club-paradiso.vercel.app`을 사용합니다.

## 검수 정책

기본 콘텐츠는 전부 `pending`. 필수 서류, 체류자격별 예외, 면제·감면, 업무별 ATM 납부 여부, 현장 순서는 확정하지 않았습니다. 수수료 숫자를 임의로 넣지 않았습니다. 선택적 단계는 직원에게 필요하다고 안내받은 경우에만 방문객이 켭니다. '기타'는 별도의 준비 화면 없이 직원에게 민원 유형을 문의하도록 안내합니다. 서류·수수료가 불확실할 때에는 각 화면의 검수 표시와 도움 요청을 활용합니다.

공식 참고: [법무부 통합신청서 안내](https://www.moj.go.kr/bbs/moj/93/561864/artclView.do), [하이코리아 민원서식](https://www.hikorea.go.kr/board/BoardApplicationListR.pt). 2026-10-22 확인. 해당 법무부 게시물은 2022년 안내이며 최신 서식의 필드와 현장 사용 버전 일치 여부는 아직 검수하지 않았습니다. 앱 설명·예시는 원문 서식을 대체하지 않습니다.

수수료 근거와 제출서류는 체류자격·신청 사유 등에 따라 다르므로 정식 운영 전 자격별 공식 자료를 다시 확인해야 합니다. 문구 '검수 완료'는 편집자가 선택하는 콘텐츠 상태이며 기관 승인을 의미하지 않습니다. 앱의 비공식 표시와 noindex는 계속 유지됩니다.

## 보안·운영 한계

- 체크 완료는 자기 신고. ATM 납부·민원 접수·허가를 자동 검증하지 않음.
- 기본 웹 보안: CSP, 프레임 차단, MIME sniffing 차단, Referrer 차단, 위치·카메라·마이크 권한 차단, HTTP 보안 쿠키, 서버 입력 검증. 외부 HTML 삽입 없음.
- 로그인에는 scrypt 암호 검증과 인스턴스 단위 요청 제한 적용. 분산 서버리스 전체를 포괄하는 지속적 로그인 제한 및 개별 운영자 인증은 정식 운영 전 필요.
- 데이터는 현장 검수 전이며 6개 언어 전문 번역자 검수 필요. 보조기기/실제 iPhone·Android 실기 테스트와 기관 보안 승인도 필요.
- PWA는 설치와 오프라인 복구 안내를 지원. 전체 안내를 오프라인 캐시하지 않음. 이미 열린 화면은 유지되지만 오프라인에서 새로 열면 연결 안내를 표시. 변경된 행정 안내를 오래된 캐시로 제공하는 것을 피함.
- 플랫폼이 IP·접속 로그를 처리할 수 있음. 앱 자체는 방문객 식별자·분석 SDK·광고 추적을 수집하지 않음.
- Vercel Preview 보호 설정이 켜져 있으면 인쇄한 QR은 일반 방문객이 열 수 없음. 팀 테스트용 공유 링크와 현장 공개 서비스 전환은 구별해야 함.

## 테스트

`npm run typecheck`, `npm test`, `npm run build`. API 통합 테스트는 인증 → 수정 → 방문객 조회 → 충돌/CSRF 차단까지 실제 route handler로 검증합니다. `.github/workflows/qa.yml`이 preview/mvp push 시 검사·빌드·32개 모바일 E2E를 실행합니다. 모바일 E2E는 `npm run test:e2e`. Playwright iPhone(WebKit)와 Pixel(Chromium) 프로젝트를 사용하며 실제 디바이스 결과와 동일하다고 보장하지 않습니다.

## 배포

Vercel의 `visable-guide` 신규 프로젝트에서 Next.js 자동 감지, build `npm run build`, install `npm ci`. `preview/mvp` 브랜치를 Preview로 배포. 기존 VISABLE 프로젝트에 연결하거나 Production 승격하지 마세요. 기본 Preview 배포는 관리자 환경변수 없이 방문객 데모만 제공하고 관리자 게시 기능은 잠겨 있습니다.

## 초기 운영 준비 상태

Preview/mvp에는 관리자 암호 해시·세션키와 비밀값이 아닌 저장소·고정 QR 설정을 배포 환경변수로 구성했습니다. 관리자 접속 암호는 별도 비공개 전달 파일에 있으며 저장소에는 포함하지 않습니다. CONTENT_GITHUB_TOKEN은 아직 소유자 설정이 필요합니다. GitHub fine-grained token을 visable-guide 하나에만 제한하고 Contents Read and write만 선택한 후 Vercel Preview의 preview/mvp 분기 전용 Secret으로 설정하세요. 토큰을 채팅이나 이 저장소에 넣지 마세요. 설정 후 다시 배포해야 적용됩니다. `content` 브랜치는 vercel.json으로 자동 배포를 비활성화하여 콘텐츠 수정마다 불필요한 앱 빌드를 하지 않습니다.
